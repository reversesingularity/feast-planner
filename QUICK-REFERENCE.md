# Quick Reference: Drive Organization

## Your New Workspace Setup ✓

### C: Drive (OS + Tools Only)
**Path:** `C:\Dev\`
**Purpose:** Shared development resources
**Size:** Small (~50-100MB)

```
C:\Dev\
└── tailwind-ui-library\  ← Extract Tailwind UI here after purchase
```

### F: Drive (All Projects)
**Path:** `F:\Projects\`
**Purpose:** All your project code and assets
**Size:** Can grow to hundreds of GB (you have 1.37TB available!)

```
F:\Projects\
└── feast-planner\  ← Current working directory
```

---

## Common Commands from F: Drive

```powershell
# Navigate to your project
cd F:\Projects\feast-planner

# Open in VS Code
code .

# After project is scaffolded:
npm install          # Install dependencies
npm run dev          # Start development server
npm run build        # Build for production
```
