## How We'll Use Catalyst with Svelte

### Approach 1: Extract Tailwind Classes
We'll take the Tailwind CSS classes from React components and apply them to Svelte components.

**Example - Button Component:**

**Catalyst React (button.tsx):**
```tsx
<button className="rounded-md bg-indigo-600 px-3 py-2 text-white hover:bg-indigo-500">
  Sign in
</button>
```

**Our Svelte Conversion:**
```svelte
<button class="rounded-md bg-indigo-600 px-3 py-2 text-white hover:bg-indigo-500">
  Sign in
</button>
```
